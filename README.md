# 📸 Lumina Studio Photo

> **Lumina Studio Photo** — Indoor Studio & Props Artistic in Medan. Modern, Classic, Natural Light & Artificial Light photography services.

---

## ✨ Features

- **⚡ Fast & Lightweight**: Powered by Next.js 16 with Turbopack and React 19.
- **🎨 Editorial Aesthetic**: Minimalist monochrome styling with Tailwind CSS & Google Fonts (*Playfair Display* & *Inter*).
- **🎭 Smooth Motion & Micro-interactions**: Lightweight Framer Motion entrance animations, portfolio lightbox, and preloader.
- **📱 Fully Responsive**: Seamless experience on Mobile, Tablet, and Desktop with custom mobile navigation.
- **📅 Interactive Booking & WhatsApp Integration**: Date picker and instant WhatsApp checkout.
- **🖼️ Curated Portfolio Gallery**: Masonry gallery with category filters and full-screen lightbox preview.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Date Utilities**: [date-fns](https://date-fns.org/) & [react-day-picker](https://react-day-picker.js.org/)

## 🚀 Getting Started

### 1. Clone Repository
```bash
git clone https://github.com/Novazeb/Next-Studio.git
cd Next-Studio
```

### 2. Install Dependencies
```bash
npm install
# or
pnpm install
# or
yarn install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for Production
```bash
npm run build
npm run start
```
